# Translation glossary

The words Marquee uses for its own ideas, in every language it ships, so
the website, the Mac app and the Windows app say the same thing the same
way. When a string uses one of these, use the word here, not a synonym.
How to add a language: [translating.md](translating.md).

## Voice

| | Address the reader as | Notes |
|---|---|---|
| English (`en`) | you | The source. Plain, friendly, short sentences. |
| Spanish (`es`) | **tú** | Neutral Spanish (no *vosotros*, no regionalisms). ¿…? and ¡…! |
| French (`fr`) | **vous** | A no-break space before `:` `;` `?` `!`, typographic apostrophe `’`, « … » for quotes. |
| German (`de`) | **du** | Lower-case *du*/*dein*. „…“ for quotes, spaced en dash ( – ) for asides, "…" written as ` …` (space before). |
| Portuguese, Brazil (`pt-BR`) | **você** | Brazilian usage (*tela*, *arquivo*, *baixar*), “…” for quotes. |

Buttons are verbs in the infinitive (es/fr/de/pt: *Guardar*, *Enregistrer*,
*Speichern*, *Salvar*), not the imperative, as each platform does.

## Never translated

Brand and product names stay exactly as written: **Marquee, Plex, Jellyfin,
Emby, Sonarr, Radarr, TMDb, TheTVDB, IMDb, Trakt, Discord, Telegram,
Pushover, ntfy, Gotify, Slack, Homepage, Homarr, Organizr, Unraid, GitHub,
OpenAPI**. So do *Plex Watchlist* (Plex's own feature name), *Quick
Connect* (Jellyfin's), *4K*, *HDR*, *Dolby Vision*, codec names and file
formats. Titles, overviews and people's names come from TMDb and are never
translated by Marquee.
